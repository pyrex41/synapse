## Scope

This policy governs the collection, storage, retention, and access controls for all search query logs generated by the Search Platform. It applies to raw query strings, session identifiers, click-through events, and any derived analytics derived from user search behavior. All engineers, data scientists, and analysts who access search query data must comply with this policy.

## Rationale

- Search queries can contain sensitive personal information (health terms, financial queries, personal names) that requires careful handling
- Query logs are a high-value data asset for relevance improvement but must be balanced against user privacy expectations
- Retention of raw query logs beyond necessary periods increases regulatory risk under GDPR and similar frameworks
- Access to query logs must be restricted to prevent misuse for user surveillance or profiling

## Policy Statements

- Raw query strings must be anonymized within 90 days of collection; anonymized logs may be retained for up to 24 months
- User-identifiable query sessions must not be exported outside of the Search Platform's designated analytics systems
- Access to non-anonymized query logs is restricted to engineers with a documented business justification approved by the data privacy officer
- Query logs must be stored in compliance with the data residency requirements of the user's jurisdiction
- Click-through and result interaction events must follow the schema defined in [[STANDARD-028|Search Relevance Scoring Standard]]
- Query logs must not be used to build individual user profiles for purposes outside of improving search relevance
