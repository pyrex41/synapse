## Overview

This page catalogues the error codes returned by the payment processing API and their corresponding gateway mappings. Error codes are grouped by source (platform errors vs. gateway-translated errors) and include recommended client handling.

All error responses use the format: `{"error": {"code": "PAYMENT_DECLINED", "message": "...", "request_id": "req_xyz"}}`.

## Platform Error Codes

These codes are generated by the payments service itself before any gateway call, or when translating gateway errors into a normalised format.

| Code | HTTP Status | Description | Client Action |
|------|-------------|-------------|---------------|
| `INVALID_REQUEST` | 400 | Missing or malformed request fields | Fix request before retrying |
| `IDEMPOTENCY_CONFLICT` | 409 | Idempotency key reused with different request body | Use a new idempotency key |
| `INVALID_STATE_TRANSITION` | 409 | Operation not valid for current payment state | Check payment state before retrying |
| `PAYMENT_NOT_FOUND` | 404 | Payment ID does not exist | Verify payment ID |
| `RATE_LIMIT_EXCEEDED` | 429 | Client has exceeded 100 req/s | Back off and retry after 1s |
| `GATEWAY_UNAVAILABLE` | 503 | All payment gateways unavailable (circuit open) | Retry after 60s |
| `INTERNAL_ERROR` | 500 | Unexpected server error | Retry with exponential backoff; contact support if persistent |

## Gateway-Translated Error Codes

These codes are mapped from gateway decline codes into normalised platform codes.

| Code | Description | Retryable | Notes |
|------|-------------|-----------|-------|
| `PAYMENT_DECLINED` | Card was declined by issuer | No | Customer must use a different card |
| `INSUFFICIENT_FUNDS` | Insufficient funds on card | No | Customer must use a different card |
| `CARD_EXPIRED` | Card expiry date has passed | No | Customer must update payment method |
| `INVALID_CARD_NUMBER` | Card number failed Luhn check | No | Input validation error |
| `FRAUD_BLOCK` | Transaction blocked by fraud rules | No | Contact support to review |
| `DO_NOT_HONOR` | Generic issuer decline | Maybe | Retry once after 24h |
| `PROCESSING_ERROR` | Transient gateway error | Yes | Retry with idempotency key after 5s |

## Key Packages

- `internal/gateway/errors.go` - `NormaliseGatewayError()` function mapping Stripe/PayPal error codes to platform codes
- `internal/handler/errors.go` - HTTP error response serialisation
- `internal/model/errors.go` - Platform error type definitions and sentinel errors
